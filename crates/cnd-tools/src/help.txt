Workspace and session calls reach every workspace in this org.
An omitted --workspace names the calling workspace.
Reads need only the workspace token. Writes need an active calling turn.
Writes act for the member whose message started that turn.
Only a workspace owner or an org admin can archive that workspace.
Archiving the calling workspace ends this turn. A member can restore it for 14 days.
Stopping or closing the calling session can end this turn.
Close refuses a running turn unless --stop-running-turn is given.
Stop with no running turn succeeds and reports idle.
Delete moves the section's workspaces to General. The default section stays.
Previews require sign-in. Open returns a private preview link.
Close of an already closed preview succeeds with closed: false.

Create uses the calling workspace's org and owner.
Omitted workspace model and effort use the owner's defaults and the default section.
Session create uses the turn sender's default model and effort.
Creates run fast only with --fast true, for a marked model.
Send keeps the session's choice when omitted. --fast false turns fast mode off.
For workspace create, session create, or send, replace --message TEXT with --message-file PATH.
Use --message-file - to read raw stdin. Message text keeps all spaces and line endings.
Keep --request-id to retry a create or send. Omission generates an ID.
--name, --title, and --first-session-title: Use plain words separated by spaces.
Avoid underscores unless the user tells you to add them.

List returns every entry unless filters or paging are given. Limit is 1 to 100.
A limited list gives hasMore. Use offset to read the next page.
--updated-since is a signed epoch timestamp in milliseconds.
--owner takes a stable member ID. Each workspace row gives its owner's ID, login, and display name.
For the sender's workspaces, use the member ID in that message's Sender line.
Use returned owner fields to identify another member. Do not infer an owner from the token or active turn.
Read defaults to concise and the newest text. Use start-line and start-offset for earlier text.
Use next.line and next.offset as the next read's start-line and start-offset.
Use names and returned links in normal answers. A session link holds workspace and session IDs.
A workspace link in a message names that workspace. Workspace and session links in an answer show as chips.
A Sent by: line names the sending session. Do not reply only to confirm it.
